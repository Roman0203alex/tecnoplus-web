# TecnoPlus

Sitio estático preparado para publicarse en GitHub Pages. Todas las páginas usan enlaces relativos.

## Páginas

- `index.html`: inicio
- `servicios.html`: catálogo y proceso de atención
- `nosotros.html`: historia, misión, visión y compromiso
- `pagos.html`: Yape y depósito/transferencia con coordinación privada por WhatsApp
- `contacto.html`: datos de contacto y redes sociales

## Publicación

Sube el contenido de esta carpeta al repositorio y deja `index.html` en la raíz. En GitHub, entra a **Settings → Pages** para seleccionar la rama y carpeta desde la que publicar.

El WhatsApp usado por los enlaces es `51922822365`; si cambia, actualízalo en `script.js` y en los enlaces de las páginas.
